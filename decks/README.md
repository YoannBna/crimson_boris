# Decks

Depose ici ton export de liste de cartes. Formats reconnus :

- **Archidekt** — export texte (`1x Edgar Markov (VOW) 234 [Commander]`)
- **Moxfield** — export texte
- **MTGO / generique** — `.dec` (`1 Sol Ring`)

Boris importe le premier fichier `.txt` ou `.dec` trouve ici, ou via le bouton
d'import de l'interface. Chaque nom est ensuite resolu sur Scryfall pour obtenir
cout de mana, type, texte, image et prix — informations absentes des exports.
